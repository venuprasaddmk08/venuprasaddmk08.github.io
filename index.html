02Featured Build

KITS Helper

A voice-activated assistant that gives the KIDS studio a spoken answer to any equipment question — built end to end on a Raspberry Pi 4.

  1. Answers spoken questions about equipment at Karunya Innovation and Design Studio in natural language.
  2. Runs a custom search engine matching questions against a knowledge base spanning 15+ Excel files — laser cutters, 3D printers, oscilloscopes, PCs, and more.
  3. Calls the Google Gemini API to generate spoken responses grounded strictly in the knowledge base, with no invented specs.
  4. Full speech-to-text and text-to-speech loop, running live on the Pi with a USB microphone.
Python/Raspberry Pi 4/Gemini API/Speech Recognition/openpyxl
